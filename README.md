# CreaTuLanding1+Diaz

Proyecto de React para la **Entrega 1: Crea tu landing**.  
Incluye los componentes base de un e-commerce: **NavBar**, **CartWidget** e **ItemListContainer**.

## ✅ Requisitos cumplidos
- Componentes dentro de `src/components`
- `NavBar` e `ItemListContainer` renderizados en `App`
- `CartWidget` renderizado dentro de `NavBar`
- Uso de props en `ItemListContainer` para mensaje de bienvenida

## 🚀 Tecnologías
- React + Vite
- CSS

## 📦 Instalación
```bash
npm install
```

## ▶️ Ejecutar en desarrollo
```bash
npm run dev
```

## 📁 Estructura
```
src/
  components/
    CartWidget.jsx
    ItemListContainer.jsx
    NavBar.jsx
  App.jsx
  index.css
```
